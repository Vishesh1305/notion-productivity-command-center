# Implementation references checked 2026-09-29

- [Notion API Create a database](https://developers.notion.com/reference/create-a-database): current API version `2026-03-11`; database creation uses an initial data source.
- [Notion API Create a view](https://developers.notion.com/reference/create-view) and [List views](https://developers.notion.com/reference/list-views): saved view creation/listing is available, including linked views on pages through `create_database`. The connected Notion client successfully created one saved view and one linked page view in an isolated smoke test.
- [Notion API request limits](https://developers.notion.com/reference/request-limits): respect `Retry-After` for 429/529, bound retries, and re-read after ambiguous writes.
- [Notion filter data source entries](https://developers.notion.com/reference/filter-data-source-entries): supported API relative dates include one week and one month from now, but no exact rolling fourteen-day value. The live Upcoming deadlines and Home appointments filters were set in Notion's desktop UI and fetched afterward; a new workspace setup must repeat those UI settings.
- [Apple EventKit access](https://developer.apple.com/documentation/eventkit/accessing-the-event-store): reading events requires full event-store permission. The bridge only fetches; it contains no Apple save or delete calls.
- [Apple event identifier](https://developer.apple.com/documentation/eventkit/ekevent/eventidentifier): an identifier may change when an event moves calendars. The mirror combines calendar key, external/event identity, and recurring occurrence date; a moved event can therefore retire one mirror row and create another after a complete fetch.
- [Notion Education Plan](https://www.notion.com/help/notion-for-education) and [database automations](https://www.notion.com/en-gb/help/database-automations): individual Education has Plus features with a one-member limit, and paid plans may create database automations. The selected workspace's actual plan and status timestamp automation still need live verification.
- [Notion Calendar and Notion](https://www.notion.com/en-gb/help/use-notion-calendar-with-notion) and [Notion Calendar apps](https://www.notion.com/en-gb/help/notion-calendar-apps): Notion Calendar can show Notion database dates, but the approved custom Home appointment requirement needs the private local mirror described in the specification. The live web app is at `https://calendar.notion.so/`; the Home link does not confirm that the user's calendars are connected there.
